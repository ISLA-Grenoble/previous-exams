**Q1 — Robustness to outliers (1 point)**
We consider a classification problem on linearly separable data. The dataset had an outlier — a point very far from the other datapoints. We trained LDA, logistic regression, and 1-nearest-neighbour classifiers on this dataset and tested on a test set from the same distribution but without any outlier. After that, we removed the outlier and retrained.

After retraining, which classifier will **not change** its decision boundary around the test points?
- (A) Logistic regression.
- (B) 1-nearest-neighbors classifier.
- (C) LDA.
- (D) None of them.

**Q2 — Bias-variance decomposition (1 point)**

Compared to model B, model A has:
- (A) Higher bias, higher variance.
- (B) Lower bias, higher variance.
- (C) Higher bias, lower variance.
- (D) Lower bias, lower variance.

**Q3 — Linear regression with L2-regularization (1 point)**

Data points: $\{(-2, 1), (-1, 3), (0, 2), (3, 4)\}$.

What is the optimal value for the bias $b^*$?
- (A) Depends on the value of $\lambda$.
- (B) 3
- (C) 2.5
- (D) None of the above answers.

**Q6 — Ridge regularization (1 point)**

## Part 2: Weighted linear regression (6 points)

Suppose we have a regression dataset with $N$ pairs $(x_i, y_i)$ where $x_i \in \mathbb{R}^p$ and $y_i \in \mathbb{R}$. We wish to fit a linear model $f(x_i) = \beta^\top \tilde{x}_i$ where $\beta$ has entries $\beta_0, \beta_1, \ldots, \beta_p$ and $\tilde{x}_i^\top = [1\ x_i^\top]$.

We minimize the following cost function:

$$L(\beta) = \frac{1}{2} \sum_{i=1}^{N} w_i (y_i - \beta^\top \tilde{x}_i)^2$$

where $w_i > 0$ are known real-valued scalars.

**(a)** Calculate the gradient of the loss function and make it equal to zero. Write an expression in matrix-vector form similar to the expressions for least-squares given in the lectures. **(2.5 points)**

**(b)** Discuss the conditions under which the solution $\beta^*$ is unique. **(1.5 points)**

**(c)** Assuming those conditions hold, write down the expression for the unique solution. **(1 point)**

**(d)** Interpret the role of the weights $w_i$ in the results of the regression. Explain how adding them to the usual linear regression model can be useful for certain situations. **(1 point)**
