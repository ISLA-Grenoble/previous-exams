## Part 1: Multiple choice questions (6 points)

Each question has exactly one correct answer.

**Q1 — Robustness to outliers (1 point)**
We consider a classification problem on linearly separable data. The dataset had an outlier — a point very far from the other datapoints. We trained LDA, logistic regression, and 1-nearest-neighbour classifiers on this dataset. We tested on a test set from the same distribution but without any outlier. After that, we removed the outlier and retrained our models.

After retraining, which classifier will **not change** its decision boundary around the test points?
- (A) Logistic regression.
- (B) 1-nearest-neighbors classifier.
- (C) LDA.
- (D) None of them.

**Q2 — Bias-variance decomposition (1 point)**
Consider a regression model where data (x, y) is generated by x ∈ R uniformly sampled from [0, 1] and y = x + ε, where ε is random noise with mean 0 and variance 1. Two models are used: model A is a trained quadratic function g_A(x, β) = β₀ + β₁x + β₂x² and model B is a constant function g_B(x) = 1/2.

Compared to model B, model A has:
- (A) Higher bias, higher variance.
- (B) Lower bias, higher variance.
- (C) Higher bias, lower variance.
- (D) Lower bias, lower variance.

**Q3 — Linear regression with L2-regularization (1 point)**
Assume we are doing linear regression with mean-squared loss and L2-regularization on four one-dimensional data points. Our prediction model is f(x) = ax + b and the optimization problem is:

a*, b* = argmin Σᵢ₌₁⁴ (yᵢ − f(xᵢ))² + λa²

Data points (xᵢ, yᵢ) are {(−2, 1), (−1, 3), (0, 2), (3, 4)}.

What is the optimal value for the bias, b*?
- (A) Depends on the value of λ.
- (B) 3
- (C) 2.5
- (D) None of the above answers.

**Q4 — PCA (1 point)**
Which of the following transformations to a data matrix X will affect the principal components obtained through PCA?
- (A) Adding a constant value to all elements of X.
- (B) Multiplying one of the features of X by a constant.
- (C) Adding an extra feature to X (an extra column) that is constant across all data points.
- (D) None of the above answers.

**Q5 — Ridge regularization (1 point)**
Assume N training samples (x₁, y₁), …, (xN, yN) where xᵢ ∈ Rᵖ and yᵢ ∈ R. For λ ≥ 0, consider:

L_λ(β) = (1/N) Σᵢ₌₁ᴺ (yᵢ − xᵢᵀβ)² + λ‖β‖₂

and let C_λ = min_{β} L_λ(β). Which statement is true?
- (A) C_λ is a non-increasing function of λ.
- (B) For λ = 0, the loss L₀ is non-convex and might have several minimizers.
- (C) C_λ is a non-decreasing function of λ.
- (D) None of the above statements are true.

**Q6 — Logistic regression (1 point)**
Consider the logistic regression loss for binary classification with data (xᵢ, yᵢ) ∈ Rᵖ × {0, 1}:

L(β) = (1/N) Σᵢ₌₁ᴺ (log(1 + e^(xᵢᵀβ)) − yᵢ xᵢᵀβ)

Which of the following is a gradient of the loss L?
- (A) ∇L(β) = (1/N) Σᵢ xᵢ (e^(xᵢᵀβ)/(1 + e^(xᵢᵀβ)) − yᵢ xᵢᵀβ)
- (B) ∇L(β) = (1/N) Σᵢ xᵢ (yᵢ − e^(xᵢᵀβ)/(1 + e^(xᵢᵀβ)))
- (C) ∇L(β) = (1/N) Σᵢ xᵢ (1/(1 + e^(−xᵢᵀβ)) − yᵢ)
- (D) None of the above.

**Q7 — Linear regression irreducible error (1 point)**
In linear regression, we model p(y | x) ~ N(βᵀx + β₀, σ²). The irreducible error in this model is:
- (A) σ²
- (B) E[y | x]
- (C) E[(y − E[y | x])² | x]
- (D) None of the above.

Which of these classifiers could have generated a highly non-linear, irregular decision boundary (as shown in the figure in the exam PDF)?
- (A) Logistic regression
